# Commits and pushes need explicit instruction

Never commit, push, tag, or open a pull request unless explicitly asked to in the current
conversation. "Save progress", "stage these", "wrap up", or an end-of-task summary are **not**
commit requests — finish the work, report it, and wait. Staging files to prepare a commit is fine
when asked; the commit itself always needs its own explicit instruction. Approval to commit once
does not carry over to later changes in the same session.

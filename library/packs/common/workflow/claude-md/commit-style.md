# Commit message shape

- Subject: short and factual — *what changed*, not why or how hard it was ("Add ports manager
  screen", not "Implement issue 0042" or "Major improvements to ports").
- Optional one-paragraph body when the diff isn't self-evident.
- No marketing language, no emojis, no "Co-Authored-By" or generated-by trailers unless the
  operator explicitly asks for them.
- One logical change per commit; don't bundle an unrelated fix into a feature commit.
